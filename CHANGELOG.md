# Changelog

## 0.1.0

- First release. Opens Microsoft Access databases read-only: .mdb (Jet 3 and Jet 4), .accdb (Access 2007 and later), .mde and .accde.
- A table list with row counts; system tables hidden until you ask for them; linked tables listed by name.
- Rows in pages, with sort by any column, a filter over all columns or one column, the whole value of the selected cell, and Copy cell or Copy row.
- Memo text, OLE objects, binary values and attachments shown safely: text as text, binary data as size, kind and hex only.
- A Schema tab with the Access type of every column.
- Databases with a password ask for it; the password is not stored.
- Zovo Pro tools: Export to CSV and JSON, Export to SQLite, Schema as SQL, Compare two Access files (1 free try each).
