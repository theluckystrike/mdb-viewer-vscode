# The schema of every table

- The Schema tab lists each table with its row count and its columns: the Access type (Short Text with its length, Number with its size, Currency, Date/Time, Yes/No, AutoNumber, OLE Object, Attachment) and whether the column is required.
- Click a table name in the schema to see its rows.
- Tick System tables in the toolbar to add the MSys tables to the list and to the schema.
- A table the reader cannot read is listed with a note. The other tables stay readable.
