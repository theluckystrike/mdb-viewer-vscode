# Third-party notices

MDB Viewer & ACCDB, Access DB ships these libraries. The JavaScript of mdb-reader and its XML helpers is bundled
into lib/mdb-reader.js with esbuild. We changed one line in it: each row object has no prototype, so a column named
__proto__ keeps its value (marked "zovo change"). sql.js is copied as published (lib/sql-wasm.js, lib/sql-wasm.wasm). All are under
the MIT license. The SQLite library inside sql.js is in the public domain.
